# Blockroom

AI previs and blocking app. Describe a scene, an OpenRouter model plans the set, cast, movement and camera shots, and the app builds it in 3D so you can record a blocking video for your video model.

Vercel environment variables:
- `OPENROUTER_API_KEY` your OpenRouter key
- `BLOCKROOM_PASSCODE` any phrase; enter the same phrase in the Direct tab
